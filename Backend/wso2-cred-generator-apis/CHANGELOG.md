## [1.0.0] - 2025-11-26

### Added

- WSO2 API Manager credential generation for tenant onboarding and partner registration
- Tenant registration and business onboarding workflows including WSO2 tenant provisioning
- API subscription management for automated assignment of partner applications to API products
- OAuth2 client credential lifecycle management including client creation, key generation, and revocation
- Auto-subscription to pre-approved API catalogue for newly registered tenants and data fiduciaries
